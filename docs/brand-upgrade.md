# Veymux 品牌升级

官网为 https://veymux.com，npm 包名和唯一 CLI 命令为 `veymux`。
应用、桌面 Bundle ID、邀请链接、通信标识、环境变量及浏览器存储统一使用新名称。

## 自动迁移

- CLI 初次启动或安装时将上一版本的用户数据目录移动到 `~/.veymux`。
  身份私钥、密码散列、会话记录、证书和 CA 保持原内容；只更新自有路径及环境变量名称。
- 桌面端在创建新配置目录之前迁移连接配置与浏览器数据目录。
- 页面在生成设备身份之前迁移浏览器设置与 IndexedDB，迁移失败时保留原数据库。
- 目标目录或目标设置已存在时以新数据为准，不覆盖新数据；原目录保留以供核对。
- 迁移重复运行安全。旧名称仅存在于集中迁移代码及对应测试中，产品界面和新数据使用 Veymux。

## 升级与发布

各端的通信标识已统一更换，服务、桌面客户端与浏览器页面应一起升级；PWA 更新后彻底关闭再重新打开。
自定义环境变量使用 `VEYMUX_*`；用户目录中的 `.env` 自动更新，系统服务或外部脚本中的变量需更新。

仓库中的发布配置已指向新包名和仓库名。真正上线前仍需设置 npm 新包、GitHub 仓库名称、
新 Bundle ID 的签名和通知权限，并把官网域名接到实际部署。这些外部发布不由本地构建代替。

## 验收

`npm run test:brand` 检查单向迁移、已有数据冲突、浏览器设备密钥与旧名称边界。
真实 macOS 的签名、通知注册、WKWebView 数据迁移以及 iOS PWA 更新需在对应设备验收。

2026-10-28 本机验收：前端、服务端、Electron 构建及 TypeScript 检查通过；
单向迁移和名称边界 10 项、Node 回归 63 项、桌面脚本回归 78 项通过。
全量 Vitest 为 6133 项通过、1 项跳过，唯一失败为系统 inotify 额度耗尽导致设置监听失效；
随后已为设置和共享会话目录增加单文件轮询兜底，相关 63 项回归通过，
并用实际子进程的原子写入验证资源耗尽后的恢复。

正式服务已保留原有 25 个会话；身份私钥、密码散列及 CA 文件逐项校验一致。
Chrome 桌面和移动视口页面无旧名称、无横向溢出或页面异常；浏览器实测设备密钥和主题自动迁移。
终端 WebGL 中间重绘检查在原始基线也有失败，已记录，未修改相关尺寸逻辑。

不同域名之间的浏览器数据受同源规则限制；换用新域名时可能需要重新邀请设备。

## 图标定稿：回流（2026-10-28）

采用用户确认的「回流」矢量稿：单条连续的开放回卷、圆润的上侧端点、宽阔的左侧
形体和非对称留白。图形采用 Flexoki cyan-400 `#3AA99F`，底色采用 bg-2
`#1C1B1A`；保留纯色，不依赖渐变或字母形状。品牌图形颜色单独由
`src/index.css` 的 `--brand-mark` 提供，沿用原有界面功能色。

彩色和单色版本共用一条手工绘制的 Bézier 路径。普通图标保持确认稿的比例；
16/24/32px favicon 放大 4% 以补偿视觉重量；Android maskable 图形缩小至 90%，
保留完整的不透明底色，让图形落在中心 80% 圆形安全区内。macOS 图标保留外边距。

此前的双斜带 V、折角窗格和双波形草稿均已弃用。卷曲和波浪是常见图形母题，
本稿的区别重点是横向开放轮廓、单一连续形体及端点与留白的比例。
本轮补充对照：

- [Microsoft Edge 官方图形与单色版本](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/mscle/documents/presentations/Microsoft_Edge_trademark_guidelines_2025.pdf)
- [Tailwind CSS 官方品牌图形](https://tailwindcss.com/brand)

此前还对照了 Vue、Vuetify、Valvoline、Warp、WezTerm、Zellij、Mobile Terminal、
Veyon 和 Void 的公开官方标识。上述检查是公开检索与人工视觉初筛，不能据此声称
全球唯一、商标可注册或不存在法律冲突；未做完整图形商标库检索或上传图片的反向搜图。

所有运行时图形、favicon、桌面 ICNS/PNG 和 39 张启动图由同一入口生成：
`npm run generate:brand-assets`。网页图标、启动图与 PWA manifest 图标统一更新资源版本，
避免继续引用旧图形的缓存 URL。浏览器预览和本机资源检查不代替 macOS/iOS 实机验收。

启动图与 HTML 首屏共用同一矢量源；网页首屏直接内嵌 SVG，避免外部图片请求带来的空帧。
两者都以视口中心、短边的 32% 绘制图标，不额外偏移；可见图形约占短边的四分之一，
加载提示随图标尺寸保持间距。`npm run test:startup` 用实际
启动 PNG 与浏览器首屏截图对比横竖屏、DPR 2/3 的轮廓位置，并检查加载阶段交接与错误恢复。
