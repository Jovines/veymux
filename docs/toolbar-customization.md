# 工具栏配置体验

## 使用路径

- 从设置的「键盘工具栏」进入，或展开终端工具栏，点切换按钮 →「自定义工具栏」。后一条路径直接编辑当前使用的那套。
- 配置页全屏显示，底部固定全宽预览，安全区只保留一次。正文独立滚动。预览直接使用 MobileKeyboard，包含手机固定按键行；按钮尺寸、字体、换行和双击标记与实际渲染相同。
- 桌面侧栏、手机横向标签直接显示工具栏列表，选中项保持可见；这一步不会强制切换终端。从终端入口打开时，可以点「在当前终端使用这套」切换并返回终端；当前自动模式下编辑同一套时保留自动模式。
- 编辑区使用键帽网格；抓住键帽侧面的手柄可拖动排序，点键帽或底部真实预览可编辑，虚线加号键帽用于添加。悬停或聚焦键帽时，底部对应按键同步高亮。新增时先显示按钮库：常用按键点一下即加入，已有按键按实际编码识别并标勾，避免重复添加。命令和文字只需填写内容，名称自动生成；点键帽上的铅笔才展开改名，是否回车明确选择。组合键直接点修饰键与小键盘中的方向键、Home、End、Tab、Enter，其他按键再展开选择。
- 常用按键立即加入后可撤销；自定义命令与组合键点添加／保存后才更新配置。返回按钮库保留本次文字草稿，取消、关闭和 Escape 都丢弃未提交的草稿；Escape 只关闭最上层。删除入口在按钮编辑器中，支持撤销最近一次修改。鼠标、触屏长按和键盘 Space + 方向键均可排序；拖动时 Escape 只取消拖动，不关闭页面。
- 手机／电脑预览使用各自实际默认按钮及 Alt、行布局规则。第一次修改默认按钮时，会保留当前预览中的其他默认按键。配置共享，编辑后的自定义按钮在两个端共用。
- 排列通过键帽缩略图和「每行 4／6／8 个」切换，立即反映到底部预览；每行按实际按钮数量均分剩余宽度，尾行仅剩一个按钮时也铺满，不再为未使用的列保留空白。名称、程序关联、Alt 与每行数量收进齿轮选项；按键编码、分步输入及双击在按钮编辑器的高级设置。已有分步命令可直接编辑文字，并保留发送间隔。
- 保存状态与撤销显示在编辑区标题旁，正常状态不占整行说明区。读取失败时禁止覆盖已有服务配置；保存失败可以重试。其他设备修改引发冲突时保留本机修改，重新读取前明确确认丢弃尚未保存的修改。

## 保存与兼容

沿用当前页面的加密 API 和既有服务端文档。修改按顺序写入，正在保存时合并后续修改，使用上一条响应的版本继续提交。旧响应或配置广播不能覆盖尚未提交的新修改；另一个客户端的真实冲突要求重新读取，不强制覆盖。

文字输入单次解码，字面反斜杠和 `||` 不会意外变成按键或分步发送。原有编码和双击字段保留，不升级或重置内置预设版本。

## 验证范围

`ToolbarPresetSettings.test.tsx` 覆盖草稿取消、按键与文字、默认按钮保留、分步命令、双击、删除撤销、恢复、冲突和失败重试。`toolbarPresetWriter.test.ts` 覆盖连续修改的顺序、合并、失败重试及冲突停止。`toolbarCustomization.browser.tsx` 使用真实组件验证 320、390、1280 像素宽度的入口、编辑、取消、焦点恢复、遮挡命中、保存反馈及视口缩小后的保存操作。另逐项比较全屏预览与应用后真实工具栏的坐标、按钮尺寸、字号、行网格和双击标记，覆盖通用终端、Codex、CustomAgent、手机横竖屏、桌面及安全区；另验证真实鼠标／触屏拖动、键盘排序与取消、撤销以及选中标签可见性。

体验检查使用隔离的临时数据，不改用户正在使用的工具栏。浏览器与自动化模拟不能代替 iOS PWA 实机软键盘、候选栏以及远端服务下的实际验收；这些仍需真实客户端确认。
