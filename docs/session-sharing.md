# Session 分享与对话

顶部导航提供终端与普通对话的一键切换，会话操作菜单保留显示方式和「分享这个会话」。终端视图不新增常驻工具栏。切换显示方式保留同一终端连接；对话的草稿和待发送引用按服务、会话保存在当前浏览器会话中。显示模式由目标服务保存，按同一 Session 在客户端间同步；本地缓存仅用于首次绘制和断线恢复。

聊天使用独立的可视高度适配，软键盘弹起时保留顶部导航，输入框随可见区域收缩；隐藏的终端不参与聊天键盘的布局信号。连续的助手消息保持原始正文顺序，共用身份，每条保留独立的引用与复制操作。用户发送后以当前 Agent 的图标、名称和「工作中…」呈现回复占位，确认和进度消息不提前结束等待，匹配的最终回复到达后结束；这表示仍在等待回复，不推断 Agent 内部运行状态。阅读历史时新回复不会强制滚到底部，可通过「查看新消息」返回。

聊天、文件预览、架构文档和协作任务共用 `src/lib/components/markdown/MarkdownPreview.tsx` 的 Markdown 渲染。宽表格和代码块有独立的横向滚动区域；聊天中的触摸由内容消费，避免被会话 Swiper 截获，抽屉内沿用侧栏手势仲裁。聊天与终端共用应用视口测量，聊天按原始可视高度和可视区域偏移定位，不再通过强制页面滚动对抗键盘动画。

邀请可以选择终端读写权限，附带具体手机、电脑和文件目录。手机和电脑分别选择仅查看或查看并操作；文件目录分别选择读取下载或修改上传删除。完整服务权限放在高级选项中。邀请链接单次使用、10 分钟内有效；访问授权可单独设置到期时间，或者保留至撤销。生成页面显示授权摘要；已接受的邀请需要在设备授权中撤销。

文件权限限制的是文件侧栏。允许终端输入或电脑控制意味着接收者能以相关系统用户的权限操作系统；共享目录不是终端命令的沙箱。受限文件接口核对规范化路径与实际路径，拒绝目录外的符号链接；编辑现有文本要求原文仍然一致，并拒绝多重硬链接。文件侧栏不开放 Git 命令、原生文件管理器或设置接口。

对话通过 TD 协作的持久消息投递，接收 Agent 使用原消息 ID 明确回复。这里只显示用户消息和明确回复，不把终端输出解析成助手答复。未识别到 Agent 时不能通过对话向普通 Shell 注入命令；可打开终端启动 Agent。网络失败可重试同一个请求，避免重复入队。拥有该 Session 查看权限的客户端共用聊天历史，兼容此前按设备保存的消息与回复，不需要迁移或重新发送。消息投递身份和重试去重保持稳定。查询只包含对应 Session 的聊天请求与明确回复，不混入其他会话或其他协作集成消息；权限以目标服务认证上下文为准，客户端请求头不能提升权限。对话依赖 Agent 实际执行 TD 回复命令，不声称推断其内部进度或已读状态。

电脑接收者使用自己的系统登录凭据；邀请不下发主机保存的密码。RDP 的只读由服务端连接参数和输入过滤共同执行。VNC 的只读过滤支持 RFB 3.8 的无认证、VNC 密码和 Apple Remote Desktop 认证；其他认证方式会明确拒绝连接。设备、文件请求与消息继续走现有加密链路，授权撤销后重新校验接口与活动流。

## 本次验证范围

自动化覆盖邀请持久化、委派与撤销、目录穿越与软硬链接、编辑冲突、手机输入过滤、VNC 分片协议过滤、RDP 直连与中转的只读过滤、聊天请求去重、明确回复、会话隔离、跨设备历史和模式同步、草稿重试及原有传输边界。浏览器体验使用隔离数据验证桌面和手机尺寸的邀请创建、取消选择、授权摘要、聊天排版、输入与失败重试；没有向生产会话发送测试消息。实际 macOS/iOS 的手机投屏、电脑登录和完整聊天往返仍需实机验收；浏览器模拟不代表实机通过。


消息支持整条引用和选中文字引用，发送前可预览、移除，保存为普通引用文本，兼容旧客户端和 Agent。输入使用 Enter 发送、Shift + Enter 换行，中文输入法确认候选词不会触发发送。图片粘贴、文件粘贴和拖拽复用现有加密上传与只读原生剪贴板读取；上传有进度、取消和重试，切换会话或服务后不再插入过期结果。跨服务的文件路径拖拽会被拒绝。原生 macOS 文件剪贴板和真实 iOS 键盘仍需实机复验。

分享页面复用既有侧栏、资源内容和宽度拖拽工具。只读终端按服务端实际网格等比缩放，不改变 PTY；获授调整尺寸权限的 tmux 查看端使用独立显示附件并随面板 resize。普通侧栏显示单 Session 共享标记、实际连接设备数及快捷停止共享。设备数去重同设备的多个连接；聊天页面用实际 Session 请求续期，终端流按实际连接统计，不视为已读。停止共享只收窄此 Session 的授权与未使用邀请，保留同一授权中其他 Session 的权限。中转始终在最终目标校验会话和资源权限。

聊天附件与文件目录授权分开：会话输入权限允许向服务端指定的独立附件目录添加新文件，不允许选择服务端路径或读取其他文件。共享手机的截图复用此链路；录像按认证设备隔离，不能列出、停止、保存或删除其他设备的录像，保存到任意目录仍须独立目录写入授权。受限页面的录屏确认仅提供添加引用和丢弃。桌面与手机尺寸浏览器已验证附件选择、图片粘贴、截图、录屏确认和引用插入；设备画面使用隔离模拟数据，不代表真实手机录屏验收。

手机选择器复用侧栏的物理设备合并规则：仅按服务端确认的 physicalId 合并 IPv4、IPv6 和 USB 路由，不按型号猜测。同一台设备显示一次、计数一次，选择、权限调整与取消选择同时作用于其已观测地址；授权仍保留精确地址白名单。新邀请等待接收时暂停旧服务的后台授权检查，旧请求的迟到结果不能覆盖新邀请；只有新连接实际返回有效目标授权后才清除旧拒绝状态。隔离服务的真实加密浏览器验收覆盖接收、刷新恢复以及另一身份重复兑换被拒绝。

## 分享外观与 OpenUI

分享可从当前会话或分屏的导航直接进入，自动选中对象；默认显示权限、打开方式、访问有效期与链接地址。名称、图标、备注和附带资源集中在一处更多选项中。每个选中的会话可独立设置分享名称和图标（内置图标或单个 Emoji），默认沿用会话名称。外观存入邀请并随兑换后的授权持久化，以稳定 Session ID 绑定；接收端标题与会话选择列表从目标服务读取，原始会话名称保持独立。仅能设置本次授权范围内的外观，收窄多会话授权时同步移除对应外观。

普通对话使用 OpenUI Lang Core / React Lang 1.0.1 与 React UI 0.18.1 的完整 82 种组件，另保留 Termdock 文件/链接资源入口。新版协议为 `openui.version=2`；旧版 14 种自定义组件的消息继续按原签名渲染。组件覆盖卡片、表格/可编辑表格、柱状/折线/面积/雷达/饼图/散点等图表、日期/滑块/单选/多选表单、标签页、折叠区、步骤、轮播、图片画廊和弹窗；绑定变量、内置函数、组合动作、设置与重置状态使用官方运行时。

Agent 提示词简洁列举可用表达能力，由 Agent 自行选择表达方式；不注入场景选型、排版偏好或组件库附带的推荐规则。明确标记“来自用户的普通对话界面”的消息可运行 `td collab ui --text` 查看签名与示例，通过原消息的 `reply --file` 和 `--metadata '{"openui":{"version":2}}'` 提交 `{ "text": "完整 Markdown 说明", "ui": "界面程序" }`。`text` 可独立阅读，供引用、复制、旧客户端和无效 UI 降级；其他协作组或后台集成不会自动进入普通聊天。终端输出不被推断为界面生成流。

逐步更新使用 `streaming:true` 创建回复，再通过 `reply <原消息> --update <回复ID> --revision <当前版本> --file <快照>` 更新同一条消息，最后设 `streaming:false`。服务端对源会话、原消息和回复身份校验，版本检查避免旧更新覆盖新内容，幂等键支持断线重试；完成后禁止继续修改该流。默认每次提交完整快照，也可设置 `patch:true` 按语句合并补丁。标准内容/上下文消息封装可以直接渲染，模型上下文不展示到正文。

表单与绑定变量自动保存到服务端消息，按修订版本检测并发编辑；冲突保留本机修改及其他客户端未修改字段，确认后重试。刷新恢复已保存状态，未完成保存保留本机恢复记录。提交前完成保存，使用字段可见名称把填写内容发为同一 Session 的新消息。只读或尚未完成的界面禁用输入与动作。

查询和变更通过应用注册的工具表执行：`Query("read_file", {path})`、`Query("list_directory", {path})` 使用现有文件授权和页面加密 fetch；`Mutation("continue_conversation", {message})` 仅在用户点击 `@Run` 后继续对话，禁止通过 Query 触发。未知工具明确报错，查询失败保留内容并提供重试。注册新工具时必须按副作用类型分开准入，不能由生成程序构造任意业务接口。

嵌套卡片、步骤、选项和正文的 Markdown 统一适配到项目共享渲染器；本地图片先经加密 fetch 转成 blob 再挂载原生图片/背景，不回退到明文业务链接。独立文件预览、界面弹窗、图片画廊沿用四边安全区与语义层级；日期控件使用系统原生选择器并保存 ISO 日期值，支持单日和范围。第三方颜色全部映射到 `src/index.css` 的 Flexoki token。按需加载组件；不挂载外部 CDN 检查器，不启用观测上报或云网关。

组件目录由 `npm run generate:chat-ui-catalog` 从锁定依赖生成，服务端/CLI 不导入浏览器组件。回归测试对账全部官方组件签名并覆盖变量、表单校验/保存、查询重试、Mutation 点击边界、消息封装、分段更新、权限与本地媒体失败；浏览器验收覆盖手机竖横屏和桌面布局、安全区。真实 iOS/macOS 软键盘与原生附件桥接仍需实机复验，浏览器尺寸模拟不代替实机。

## 浏览器分享验收与迭代（2026-10-24）

- 共享终端接入页面加密上传：支持图片/文件粘贴、文件选择、图片及文件拖拽，使用当前 Session 的独立附件目录，不要求开放任意文件目录。提供进度、取消、重试；只读授权禁止上传和输入，切换会话后不插入迟到结果。支持 Ctrl/Cmd+V 和选区复制；可操作分享沿用普通终端的 tmux 选区复制，只读分享使用本地选区，两者均可直接拖选，无须按住 Shift。
- 分屏标题及侧栏分屏布局菜单可直接“分享此分屏”，预选该分屏中的 Session。接收页支持两个会话同时显示，桌面横排、窄屏纵排，并为每个会话分别应用输入及尺寸权限。共享页的会话目录与资源授权只读取一次，再供两个面板使用。
- 同一服务的协作组菜单提供“分享组内会话”。邀请固定包含生成时选中的成员 Session，不自动开放之后新增的成员，也不包含组消息、任务看板及工作组管理权。跨服务协作组尚不支持一个邀请统一授权；未加载或不属于当前服务的成员会阻止生成不完整的邀请。
- 首次接收邀请会切换存储作用域并重载页面；默认视图、分屏偏好必须在已认证连接的目标元数据中随目标一起保存，不能依赖 `connectDevice` 返回后的回调。链接里的布局信息只影响呈现，不增加授权。

本轮使用 Linux Chrome、隔离 HTTPS 服务、真实 tmux 与真实单次邀请验证：首次加载无 Service Worker 控制、浏览器剪贴板图片（按键及粘贴按钮）、图片/文本文件拖拽事件及服务端落盘、选区进入系统剪贴板、终端重连、传输暂停后的上传取消、强制断开加密 Socket 后无直接 HTTP 回退；还验证了分屏邀请的首次接收、桌面/390×844 排列、组成员预选，以及真实只读邀请拒绝粘贴/拖拽并保留复制。测试数据与脚本置于仓库外，未向工作会话发送测试输入。文件拖拽由浏览器 DataTransfer 事件驱动，未声称覆盖操作系统文件管理器的实际拖动。

### 共享终端直接拖选复制的修正

此前将 Shift+拖选记作共享终端的完成方案不完整。共享页现复用普通终端的 OSC 52 处理及 tmux 选区读取校验；复制请求在原加密终端 Socket 内按 reqId 关联，断开或卸载时清理等待，不复制过期返回。首次快照与重连回放中的 OSC 52 不改写系统剪贴板。只读终端使用 xterm 的公开鼠标选项保留本地直接拖选，不向 tmux 发送鼠标输入。

### 分享操作流程简化（2026-10-24）

浏览器基线：从“服务与设备”进入邀请，再选择会话、勾选并确认、生成、复制，基本路径需 7 次点击；有效期和地址藏在更多设置内的子折叠。当前会话导航新增明确的“分享”入口，分屏导航传入完整成员范围。默认只读，使用当前视图；“生成并复制链接”合并创建与复制，默认路径变为两次点击。访问有效期支持直到撤销、1 小时、1 天、7 天与自定义；它与链接 10 分钟内单次接受的有效期分开说明。localhost 有已知可用地址时优先建议服务地址，手动选择不会被后续地址刷新覆盖。

默认表单不要求编辑外观，不挂载资源查询；更多选项一次显示外观、备注、其他范围和资源设置。结果直接呈现链接与授权摘要，复制操作固定在底部，二维码按需显示。复制在点击任务内通过 Promise 支持的 ClipboardItem 提前启动；复制失败保留已生成链接并允许重试，不重复生成邀请。未完成生成或已关闭页面的迟到结果不改写新界面状态。

### 局域网首次访问证书引导（2026-10-25）

已配置本机 CA 的局域网 IP / `.local` 直接分享，会生成 HTTP `/connect` 引导链接；公开域名、自定义未知地址和备用入口保持原 HTTPS 链路。引导只显示公开证书、按设备区分的安装步骤、信任范围、核对指纹和「继续访问」，不加载业务数据、不创建身份或接受邀请，也不会通过 HTTP 请求业务 API。证书下载继续兼容 `/ca`、`/onboarding/ca.crt` 与 `/onboarding/ca`。

邀请内容仅放在 URL fragment 中，HTTP 请求不携带邀请秘密；继续按钮使用当前主机与服务固定 HTTPS 端口恢复原邀请，保留普通对话 / 终端和分屏信息，不接受 query 中的任意跳转地址。HTTP 引导本身不能认证设备，必须通过原可信对话核对证书 SHA-256 指纹后安装；网页不能替代系统确认，根证书信任的范围超出当前分享。分享结果页提供经加密设置接口取得的指纹供双方核对。
