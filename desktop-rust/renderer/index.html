为什么安装应用后还要准备环境？
桌面应用负责打开工作空间；本机终端由独立服务运行。首次使用需要 Node.js 和 Veymux 服务，页面会按缺少的项目逐步引导。

            
退出桌面版，任务会停止吗？
退出桌面版只关闭窗口，本机服务和终端会话会继续运行。再次打开即可继续工作。
